PLC-Based Start, Stop and Emergency Stop Control System

Description

This project demonstrates the development of a PLC-HMI control system using CODESYS. The system incorporates Start, Stop, and Emergency Stop functions implemented through Set/Reset latch logic to simulate a basic industrial machine control operation.
The project includes PLC programming, variable mapping, and HMI visualization, enabling users to control and monitor the system through an interactive graphical interface.
The Emergency Stop function provides an additional safety mechanism by immediately resetting the system when activated.

Technologies Used

* CODESYS V3.5
* Ladder Logic Diagram (LD)
* HMI Visualization
* PLC Logic Simulation

Features

* Start and Stop control functionality
* Emergency Stop safety interlock
* Set/Reset latch implementation
* Real-time HMI interaction
* PLC and HMI variable integration
* Simulation-based testing in CODESYS
