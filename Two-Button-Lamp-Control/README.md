Two-Button Lamp Control Using PLC and HMI

Description

A simple PLC-HMI project developed in CODESYS to demonstrate AND logic operation. 
The indicator lamp turns ON only when both push buttons are activated simultaneously. 
The project showcases basic PLC programming, HMI visualization, and real-time interaction between control logic and the user interface.

Technologies Used

CODESYS V3.5
Structured Text (ST)
HMI Visualization
PLC Logic Simulation

Features

Two-button AND logic control
Real-time HMI interaction
Visual status indication through a lamp
PLC and HMI variable integration
Simulation-based testing in CODESYS
